# Rime 上游功能对照

核对日期：2026-11-15。雾凇上游 commit：`927e1cf1d3eeb9bf4be85e3f684dba4dd485b6f6`。
对照对象是本仓库的 Fcitx5 Rime source，不代表真实 home 中已经应用的配置。

后续公共工具合并及当前状态以 [Rime 功能全表](rime-features.md) 为准；日期已补充中英文格式，计算器和数字金额转换已公共化，下表保留最初对照记录供参考。

## 自动更新范围

- Tiger：`master` 分支，完整码表、OpenCC 数据；网站启动器后续已移除；常用词典按字准入预生成。
- Ice：`main` 分支，`rime_ice.dict.yaml`、`cn_dicts`、`en_dicts`、Emoji 映射。
- 两者均由 Git external 管理独立 checkout，完整 apply 时先更新，再渲染词典模板。
- 本地方案和 Lua 不自动替换，因此不会因为拉取上游就自动启用下表功能。
- 固定版本的 `rime_bigfiles` 压缩包不再使用。

## 雾凇有而本地尚未启用的功能

| 功能 | 作用 / 例子 | 当前状态与代价 |
| --- | --- | --- |
| 英文词典与补全 | 中文模式直接输入英文单词 | `melt_eng` 翻译器和依赖未启用；可能增加中英文重码。需接入英文词典及方案。 |
| 中英混合词库 | 输入 iPhone、QQ 等混合词汇 | 本地 `cn_en` 配置原已注释，但翻译器残留启用；本次把残留组件也注释，避免无配置运行。需配置双拼相应编码词表后才能使用。 |
| 英文自动大小写 | 大写开头得到首字母大写，多个大写字母得到全大写 | `autocap_filter` 未启用，适合与英文词典一同接入。 |
| 降低短英文候选 | 将容易与中文拼音撞码的英语词放后面 | `reduce_english_filter` 未启用；不开英文混输时意义不大。 |
| 拆字反查 | 用组成部件的拼音找不知道读音的汉字 | 后续已默认开启：开头反引号进入；全拼、小鹤各用独立拼写索引，共用上游部件词典。 |
| 部件辅码筛选 | 拼音后输入反引号和部件拼音缩小候选范围 | 后续已默认开启 `search`；拼音后反引号加部件拼音筛选，区别于开头反引号拆字反查。 |
| 候选置顶 | 指定编码优先显示某些已有词，例如常用名字 | `pin_cand_filter` 未启用；本地有配置样例但未参与处理。 |
| 大字表 | 在拼音里输入更多生僻字 | `cn_dicts/41448` 默认未导入；词表已随 upstream 存在，不会仅因文件存在就编译启用。增加候选和部署成本。 |
| UUID | 输入 `uuid` 生成标识符 | 翻译器未启用。 |
| 词汇别名与转写 | 月份英文、词语翻译、简称、化学式等 | 雾凇 `opencc/others.txt` 不在共享 Emoji 映射中，需单独决定是否接入。 |
| 中文 / 英文日期扩展 | `datezh` / `dateen` 风格的日期与更多日期格式 | 当前仍使用本地日期 Lua；上游日期模块更丰富，迁移需保留本地触发词，不能只替换同名文件。 |
| 农历输出格式模板 | 调整生肖、干支、月份和日期的组合 | 本地农历功能已启用，但仍用旧 Lua，未同步上游新模板配置。 |
| 模糊音 | n/l、前后鼻音、平翘舌等兼容 | 本地全拼仅有部分 u/v 兼容，未加入这些模糊音规则；上游也是可选项。双拼需另行适配。 |
| 语法模型 | 尝试改善长句选词与组句 | 未配置模型；需要额外下载模型文件和插件能力，会增加内存、部署和维护成本，提升不保证。 |
| 多条整句候选 | 调大 `translator/max_sentences` | 本地未设置；需要 librime ≥ 1.17.0，可能增加计算量。 |
| 主动 GC | 上游 `force_gc` 垃圾回收组件 | 本地未启用，属于运行机制而非输入功能，是否有益应实测。 |
| 其他双拼与九键 | 自然码、微软、搜狗、ABC、紫光、拼音加加、T9 | 本地仅保留小鹤与全拼，不自动增加方案。 |

已具备：以词定字、错音错字提示、日期、农历、公历转农历、数字金额转换、Unicode 输入、计算器、简繁转换、Emoji、符号输入、自定义短语、长词补全。部分触发词和上游不同；日期脚本尤其需要按实际模块核对。

## Emoji 对比与合并

统计源：本次下载的虎码包 `opencc/emoji.txt` 与上述 Ice commit 的同名文件。

| 项目 | 触发词数量 |
| --- | ---: |
| 虎码 | 10,608 |
| 雾凇 | 4,857 |
| 共同触发词 | 2,455 |
| 共同且输出和顺序完全一致 | 1,278 |
| 共同但输出或顺序不同 | 1,177 |
| 仅虎码 | 8,153 |
| 仅雾凇 | 2,402 |
| 合并后 | 13,010 |

虎码词条范围更宽，包含较多成语画谜、国家名称、肤色变体及文字转写；候选也更多，部分输出本身重复。雾凇常用词的候选更精简，并包含较新的 Emoji（设备字体可能尚不能显示）。

例子：

| 触发词 | 虎码 | 雾凇 |
| --- | --- | --- |
| 笑 | 😀 😁 😂 🤣 😃 😄 等较多候选，含重复项 | 😄 😊 |
| 猫 | 🐈 🐱 及多种猫脸 | 🐱 |
| 牛逼 | 🐮🍺 等组合 | 👍 |
| 疲惫 | 😫 | 🫩 😩 |
| 眼袋 | 无 | 🫩 |
| 日新月异 | 🌞❤🌙👆 | 无 |

现在两套方案都使用 `shared_emoji/emoji.json`。合并顺序为原文字、雾凇候选、虎码额外候选；按完整字符串去重，不改变 Unicode 变体选择符、ZWJ 或肤色，因此视觉相似但编码不同的 Emoji 仍可能同时出现。此策略保留覆盖范围，代价是开启 Emoji 后候选可能比雾凇原来更多。

雾凇的 `others.txt` 是另一份转换表（并非 Emoji），本次没有合并；虎码自身 `emoji.txt` 已包含的文字输出则保留。虎码默认 Emoji 关、雾凇默认开，开关仍按方案独立控制。

两个方案也都提供简繁、日期、数字金额、计算器等，但调用的 Lua 模块和触发方式有差异。本次仅统一 Emoji，不合并这些处理链，避免改变日常输入。
